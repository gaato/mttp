# mttp_schemagen prototype

An unpublished, separate tool module using `moonbitlang/parser@0.4.8`.
It is deliberately outside the repository's `moon.work` and `modules.tsv`:
the parser's transitive `moonbitlang/async` must not affect consumers or
the workspace resolver. Generated files import only the consumer's existing
`@schema` / `@jsonkit` packages and are checked in as ordinary MoonBit.

From the repository root, on the pinned 0.10.20 toolchain:

```sh
moon -C tools/schemagen run . --target wasm -- \
  "$PWD/mttp_core/src/openapi/note_schema_test.mbt" \
  "$PWD/tools/schemagen/note.input"
moon -C tools/schemagen run . --target wasm -- --check \
  "$PWD/mttp_core/src/openapi/note_schema_test.mbt" \
  "$PWD/tools/schemagen/note.input"
moon -C tools/schemagen test --target wasm --deny-warn
```

Arguments are `[--check] OUTPUT INPUT [INPUT ...]`. Pass all annotated types
from the same package, in deterministic order. A normal output name is
`<name>_schema.mbt`; tests use `_schema_test.mbt` to keep fixture types private
to their test package. `--check` compares the final bytes without writing.

The executable calls the active toolchain's `moonfmt -` using stdin/stdout
before comparing or writing. Keep `moonfmt` on PATH beside `moon` / `moonx`.
The parser's own formatter was rejected in this trial because it emits
typed-arrow syntax unsupported by moonc 0.10.20. The portable Wasm executable
can be run with `moonx gaato/mttp_schemagen` after adoption and publication;
no registry publication was performed for this prototype. A local `moon.pkg`
rule for a single input/output can use:

```moonbit
rule(
  name: "schema",
  command: "moon -C /absolute/path/to/tools/schemagen run . --target wasm -- \"$mod_dir/$output\" \"$mod_dir/$input\"",
)
dev_build(rule: "schema", input: "model.mbt", output: "model_schema.mbt")
```

Paths are made absolute because `moon -C` changes the tool's working directory.
After publication the command can be
`moonx gaato/mttp_schemagen $output $input`.
The precondition trial separately verified `rule` / `dev_build` calling a
local `.mbtx` via `moonx`, with no tool dependencies in the caller's module.
The actual local-module rule above was also tested with a fresh consumer:
one Wasm round-trip test passed, and its only module dependency was
`gaato/mttp_core` (resolved to the local checkout in the scratch workspace).

## Input and output

```moonbit
#mttp.schema
struct Note {
  /// The note title, at most 20 characters.
  #mttp.codec(title_codec)
  title : String
  stars : Int
}
```

The output is `note_codec = @schema.object2(...)` with typed field getters,
the hand-written `title_codec`, and a field description. Public types produce
public codec values. Type names become snake_case codec names; a `schema(name=...)`
overrides the JSON Schema component name.

Supported syntax mappings: `Int` / `Int32`, `Int64`, `Double`, `Bool`, `String`,
`Json`, `Array[T]`, `Map[String,T]`, `T?`, `@jsonkit.Presence[T]`, and annotated
same-package types. `T?` uses `option`, including explicit null; `omittable`
requires `T?` and refuses null. `codec(...)` supplies the value codec inside
an optional / Presence wrapper; for other types it replaces the whole codec.
It can contain a MoonBit expression, including validators.

Field attributes: `rename("wire")`, `codec(value)`, `omittable`, repeatable
`example("<JSON text>")`, and `default(identifier)`. Examples/defaults only
document values, following the existing codec APIs. Doc comments become
descriptions. Validators remain hand-written codecs. Unknown/duplicate
attributes, invalid examples and unsupported types produce file:line:column
errors. Generic declarations, tuple structs, empty structs and structs with
more than 16 fields are refused.

Argument-less enums become `string_enum(...).map(...)`. Enums whose every case
has one unlabeled, annotated same-package struct become `tagged` / `case_`.
The prototype chooses the discriminator `type` and case names as tags; the
runtime fixture tests this convention. Enums admit 1 to 64 cases. Self-recursive
structs use `recursive`, including through arrays/maps/options. Mutual recursion,
mixed enums and arbitrary external type inference are outside this prototype.

## Reproduction and measurements

`note.input` / `note.golden` pin generated bytes. The checked-in OpenAPI tests
compare the hand-written and generated Note's schema, OpenAPI JSON, ordered
Issue lists, encoding and round trips; other fixtures compile and exercise
enums, named references, metadata, collections and recursion on four targets.

```sh
moon run tools/schemagen/measure_shortlinks.mbtx -- \
  /home/gaato/works/mttp-trial/shortlinks/api/api.mbt \
  /var/tmp/mttp-plan/scratch/s/shortlinks "$PWD/tools/schemagen"
```

The script reads the original, writes only scratch copies and generates all
five codecs. Physical lines, including declaration `///|` markers:

| Codec | Hand-written lines removed |
|---|---:|
| link_codec | 10 |
| link_patch_codec | 11 |
| new_link_codec | 7 |
| created_codec | 8 |
| error_body | 6 |
| Total | 42 |

Added: 10 attribute lines and 9 wrapper/adapter lines. `error_body` originally
encoded a String as an object, so it needs an `ErrorBody` struct and a map
adapter; these are charged to the total. Net saving: 23/42 = 54.8%, excluding
generated files. The original source is never modified. Existing trial-source
deprecation warnings are separate from generator correctness.

The two description APIs, their documentation and tests are a separate logical
change from this tool; no other production API or dependency is added to core.

Verified on 2026-11-17 with moonc 0.10.20+65efd5b93:

unpublished and unregistered in the root workspace. Working time was about
35 minutes, excluding the interrupted process's stalled hours.
