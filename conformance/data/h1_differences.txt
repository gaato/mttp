# Where mttp's codec reads an imported HTTP/1 case otherwise than its source
# expects. scripts/gen_vectors.mbtx moves each `diff` case into the table of
# documented differences, with the reason above it and the source's own
# expectation kept beside mttp's; `kind` names mttp's ParseKind where both
# refuse but the default mapping of the source's error names another.
#
# `reason <text>` applies to the entries after it. An entry is
# `diff <case id> => <reading>` or `kind <case id> => refused <Kind>`, the
# reading's lines joined by " ; " (see "the outcome model" in the
# generator). Every entry must match a case, and every diff must differ.

# --- web-platform-tests fetch: where browsers' consensus is laxer or stricter than RFC 9112

reason The bytes are the same as those of `SP at <before-reason>`, which the table expects to be valid: a reason phrase may start with SP (RFC 9112 section 4: reason-phrase = 1*( HTAB / SP / VCHAR / obs-text )), so mttp reads both.
