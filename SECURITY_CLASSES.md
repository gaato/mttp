# HTTP security classes

This is a class ledger, not a claim that the listed CVEs affected mttp. The
CVEs are representative incidents in HTTP clients, servers and codecs; the
fourth column says which mttp boundary owns the analogous risk. A cited test
must exercise the stated defense, not merely the feature beside it.

Test citations use the same form as [RESOURCE_BOUNDS.md](RESOURCE_BOUNDS.md).
`scripts/bounds_check.mbtx`, run by the static gate, checks that every cited
file and exact test name exists. `gap` means that a feature, rather than a
missing regression test for existing behavior, is still planned.
