# gaato/mttp-digest

Origin-scoped Digest authentication for the
[`gaato/mttp`](https://mooncakes.io/docs/gaato/mttp) client. It lives in its
own module so that clients that do not use it do not download
`moonbitlang/x`.

> **Status**: this version is being rebuilt in the
> [mttp repository](https://github.com/gaato/mttp). Until then this module has
> no public API.

## Install

```sh
moon add gaato/mttp-digest
```
