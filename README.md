# seeds/wf2

Source-only snapshots of throwaway prototypes made while designing mttp (design/design.md §10 cites them by their
scratchpad paths `wf2/...`). Not built by CI. Used as starting points for h1, mttp-net/server, fetch, the resolver gate
and schema unions. `runtime/core-async/*` were packages dropped into a moonbitlang/core checkout (see SNAPSHOT.txt).
